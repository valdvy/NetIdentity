# NetIdentity

> **Doit-on s'identifier sur Internet ?**  
> Un dossier interactif complet sur l'identification numérique — débat, veille sourCée, fact-checker et sondage.
---

## 📁 Structure du projet

```
NetIdentity/
├── index.html        ← Page d'accueil (landing page)
├── main.html         ← Dossier complet interactif
└── README.md
```

## 🚀 Fonctionnalités

| Feature | Description |
|--------|-------------|
| ⚖️ **Débat** | Arguments pour & contre l'identification, sourCés et nuancés |
| ✅ **Fact-Checker** | 6 affirmations cliquables · révèle les vrais chiffres + sources |
| ⚡ **Veille 2026** | ARCOM, FBI, CNIL, Europol, deepfakes — données récentes |
| 📊 **Sondage** | 25 réponses · 9 questions · graphiques animés au scroll |
| 🕵️ **Expert Avatar** | Expert en cyber |
| 🔗 **Source Tooltips** | Chaque chiffre clé → popup avec lien officiel au survol |
| 🧲 **Magnetic Hover** | Effet de tilt 3D sur les cartes |
| 🌌 **Particle BG** | Canvas animé avec réseau de particules (index.html) |

## 📊 Chiffres clés couverts

- **79%** des enfants ont un téléphone avant 11 ans *(CNIL / CSA, 2023)*
- **10,5 ans** — âge moyen du 1er accès à la pornographie en France *(ARCOM)*
- **2,3 millions** de mineurs sur des sites pornographiques/mois *(ARCOM, 2024)*
- **$10 500 Md** — coût mondial de la cybercriminalité d'ici 2025 *(Cybersecurity Ventures)*
- **+900%** d'augmentation annuelle des deepfakes *(DeepMedia)*
- **16 000** plaintes reçues par la CNIL en 2023
- **850 millions** de personnes sans pièce d'identité officielle *(Banque Mondiale)*

## 🛠️ Stack technique

- **100% Vanilla HTML/CSS/JS** — aucune librairie externe
- Polices : `Playfair Display` + `DM Sans` via Google Fonts
- Animations : `IntersectionObserver` + CSS transitions
- Canvas 2D pour le fond particules (index.html)
- Accessible : navigation clavier sur le Fact-Checker
